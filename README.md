# Void Circuit

A roguelike hover-racer for iPhone and Steam (Windows/macOS/Linux), built in Godot 4. Each run is a trip
through a branching league of races: draft mods between events, protect your hull, and spend salvage on
permanent unlocks when the run ends.

- Milestones: [docs/ROADMAP.md](docs/ROADMAP.md)
- Current status: [docs/HANDOFF.md](docs/HANDOFF.md)
- Mac setup: [docs/MAC_SETUP.md](docs/MAC_SETUP.md)
- Working with Claude: [CLAUDE.md](CLAUDE.md)

## Quick start

```bash
make setup   # toolchain
make check   # lint + format check + tests
make shots   # render frames to reports/shots/
```

Open the project in Godot by choosing `project.godot` from the Project Manager.
